# DClutter 1.1.0 — At your pace

Some people decide one file at a time. Others hold an arrow key until something
looks worth a closer look. DClutter 1.1.0 gives that second workflow a pace of its
own, along with a cleaner layout and a fix for a folder-picker bug reported by a user.

## What's new

- **Set your own pace.** Hold ← or → to keep or stage files at 0.5–8 files per
  second, adjustable in 0.5 steps. The default is 3. At 0.5, each repeat waits
  two seconds. Single presses stay immediate, and releasing the key stops the hold.
- **Settings on the left.** The gear button brings together hold speed, an
  optional Confirm “Add folder…” switch, and the controls guide. Open Settings
  with ⌘, or jump to the guide with ?.
- **A cleaner file card.** The preview comes first, with the filename, badges,
  and metadata together underneath. Stage, Skip, File, and Keep buttons sit
  below the card, and the footer shows your session counts.
- **Click to file.** Open the destination shelf with File or ↑, then click a
  folder to move the file there. Keyboard and trackpad filing still work.

## Fixes

- Scrolling upward or pressing ↑ inside an open destination picker no longer
  opens more pickers. Scrolling and navigation stay inside the picker.
- Rapid decisions and Undo no longer race an earlier card's exit animation.
- Holding an arrow stops when the window loses focus or a dialog opens, and
  missed repeats never build up into a burst.

Confirm “Add folder…” is **off by default**, so releasing a swipe over Add folder
still opens the picker immediately. Turn it on if you'd prefer to press Return
or click first. Existing destination folders still file on release.

Files staged for trash stay on disk until you review the list and confirm.
Filing moves immediately and remains undoable.

## Install

Download **DClutter-1.1.0.zip**, unzip it, and drag **DClutter.app** into Applications.
The archive includes **READ ME FIRST.txt** with installation instructions and controls.

This build is not signed with an Apple Developer certificate or notarized. If
macOS blocks the first launch, open **System Settings → Privacy & Security**,
choose **Open Anyway** for DClutter, and confirm **Open**.

Universal app for **Apple Silicon and Intel**, requiring **macOS 14 or later**.

Thanks to the users who reported the picker bug and shared how they work through
their files. Feedback and small annoyances are welcome in
[GitHub issues](https://github.com/RokiTheWise/DClutter/issues).
